# Trip Itineraries

Kratisha and Shyam's trip plans, day by day, published with GitHub Pages.

- `index.html`: the landing page that lists every trip.
- `sri-lanka-maldives/`: Sri Lanka and the Maldives, 21 Nov – 10 Dec 2026.

To add a trip, put its page in a new folder (for example `france-germany/index.html`) and add a card for it to `index.html`.

Photos are hotlinked from [Wikimedia Commons](https://commons.wikimedia.org/) and credited on each page. Booking references, payment details and passport details are deliberately left out.
